### Capabilities
1. Draw - draw current board
2. List - show list of figures
3. shapes - show list of shapes
4. add - add a new figure
5. select - select shape by ID or cordinates
6. remove - remove a shape
7. edit - edit params of a selected shape
8. paint - edit color of a shape
9. move - edit a position of a shape
10. clear - remove all shapes
11. save - save to file
12. load - load from file
